# Tic Tac Toe

A simple Tic Tac Toe game built using HTML, CSS and JavaScript.

## Features

- Two-player game
- X and O turns
- Win detection
- Draw detection
- Restart Game button

## Technologies Used

- HTML
- CSS
- JavaScript

## How to Run

1. Download or clone the repository.
2. Open `index.html` in a web browser.
3. Start playing Tic Tac Toe.

## How to Play

- Player X starts the game.
- Players take turns clicking an empty box.
- The first player to get three symbols in a row wins.
- If all boxes are filled without a winner, the game is a draw.
- Click **Restart Game** to start a new game.
